# Nnaji Iheaku — Cybersecurity Portfolio

A responsive one-page cybersecurity portfolio inspired by modern technical portfolio sites, built from scratch with HTML, CSS, and vanilla JavaScript.

## Preview locally

Double-click `index.html` to open it in your browser.

## Publish with GitHub Pages

1. Create a GitHub repository such as `portfolio`.
2. Upload `index.html`, `styles.css`, and `script.js`.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/root`, then save.
6. GitHub will generate a public website URL.
